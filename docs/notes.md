# Notes

This file is for short design notes and working observations that are useful
locally but should not become a second roadmap.

The source of truth remains:

- [AGENTS.md](../AGENTS.md) for repo instructions and boundaries.
- [memory-bank/product.md](../memory-bank/product.md) for product scope.
- [memory-bank/architecture.md](../memory-bank/architecture.md) for system
  design and ownership.
- [memory-bank/tech-stack.md](../memory-bank/tech-stack.md) for dependencies,
  commands, and tooling rules.
- [memory-bank/milestone.md](../memory-bank/milestone.md) for active tracks and
  status-file sequencing.

Use this file for concise notes that do not yet justify a memory-bank update.
If a note changes product direction, architecture, command behavior, milestone
scope, or status tracking, move that decision into the memory bank instead.
